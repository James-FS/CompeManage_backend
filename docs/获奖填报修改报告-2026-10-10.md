# 获奖填报修改报告

日期：2026-10-10

## 完成结果

获奖填报已改为按学生逐行录入、按“赛事＋参赛项目名称”归组为团队。报名不再是数据库中的必需关联；全赛事报名开关初始关闭。前后端代码及测试已完成，项目实际数据库的结构升级将在后端下次启动时自动执行。本次数据库验证使用独立临时库，没有对项目现有业务数据执行迁移。

## 模板与导入页面

模板列顺序统一为：

**序号、学号、学生姓名、所属学院、所在专业、参赛项目名称、获奖时间（年/月）、获奖类别、获奖等级、备注。**

- 删除承办单位，继续使用赛事创建时已有的信息。
- 两处下载入口使用同一个后端模板生成接口，避免前后端模板不一致。
- 学号和获奖年月列使用文本格式；时间填写 `YYYY-MM`。
- 数据区下方直接加入获奖类别、等级换算、学生资格和填写要求说明。
- 等级换算及全日制本科生资格仅作为模板说明，不进行自动换算或学籍资格限制。
- 示例行标记为“示例”，不参与导入；说明行和空白行不参与导入。
- 按表头名称识别数据，支持调整列顺序；旧模板缺少必要字段时明确要求下载新版。
- 支持读取 Excel 后编辑、删除预览行、手动“新增一条”，也支持完全不上传 Excel 直接填写。
- 提供后端预校验；提交时再次校验，错误逐行显示。每批最多 5000 行。

获奖类别支持“校赛、国家级、省级、国际级”，国际级统一保存为国家级。获奖等级按填写文字保存。

## 团队与数据校验

- 项目名称去除首尾空格后，在同一赛事内按相同名称归组。不同赛事互不合并。
- 同组学生的获奖类别、等级和年月必须一致；与已有团队奖项冲突时提示更正，禁止通过导入覆盖。
- 学号匹配系统账号，姓名、学院及填写的专业与系统资料核对；专业留空时使用系统专业。
- 同一文件中，同团队同学生重复填写会报错。
- 数据库中已存在同团队同学生时提示“已存在”，不覆盖备注或转移填报归属。
- 导入在事务内执行，任何校验或写入错误都会回滚整批。返回学生数、团队数、新增数及已存在数。
- 导入不创建虚假报名，也不修改原报名团队名称。存在唯一审核通过报名时记录成员的报名关联；新增获奖成员关联的报名状态按原业务更新为已获奖状态。

不同团队若使用相同项目名称，会被视为一个团队，模板内已明确提醒。

## 权限规则

| 操作 | 实现规则 |
|---|---|
| 院管理员查看填报赛事 | 本管理学院赛事＋级别为“校级/校赛”的赛事 |
| 导入学生 | 可包含其他学院学生，仍需满足赛事访问权限和身份资料校验 |
| 编辑成员 | 校管理员，或与首次填报学院一致的院管理员 |
| 编辑团队共享信息 | 校管理员，或当前团队成员所属学院的院管理员 |
| 重复导入归属 | 保留第一次填报学院与提交人 |
| 确认历史填报学院 | 仅校管理员可确认，已有归属不因重复导入转移 |

成员编辑支持修正学号和备注。修正学号后，姓名、学院、专业由系统账号资料更新，不能伪造这些身份信息。修改不会改变填报学院。团队编辑支持项目名称、类别、等级和年月，修改影响该团队所有成员；同名项目已存在时不自动合并覆盖。

后端对直接请求接口也执行权限检查。已补齐院管理员的 `award:import` 权限，并在启动时清理该权限的旧 Redis 判断缓存。

## 报名开关

入口：以校级管理员身份进入“导入获奖名单”，顶部可调整“所有赛事获奖导入要求审核通过的报名”。其他填报角色只能查看状态。

- 配置持久化到数据库，初始关闭。
- 关闭：允许无报名学生导入，仍校验身份、数据和权限。
- 开启：每位学生必须作为负责人或成员参加过目标赛事且报名已通过审核。
- 作用于所有赛事，不限校赛。
- 切换仅影响后续导入；历史记录仍能查看和按权限编辑。

## 数据库和关联功能

| 内容 | 调整 |
|---|---|
| `awards` | 新增项目名称、项目唯一标识、获奖类别及成员迁移标记；报名关联允许 NULL；保留已有年月时间、审核和来源字段 |
| `award_members` | 新增实际获奖学生、可选报名关联、身份快照、备注、首次填报学院、提交人与时间 |
| `award_import_settings` | 新增全赛事有效报名要求开关 |
| 唯一约束 | 同赛事同项目一个团队；同团队同学生一条成员记录 |

旧奖项按原报名资料补充可匹配的获奖成员，不推断历史填报学院。迁移使用标记避免重复补充，也不会在后续重启时恢复已经修正的旧成员。无法匹配系统账号的历史成员保留原报名资料，并输出奖项 ID 与待核对数量日志。

校管理员可在“获奖详情 → 获奖成员 → 编辑”中确认未确定的填报学院。旧记录的类别或年月若缺失，需先更正团队信息；历史同名冲突需核对处理，不擅自合并。

关联调整已覆盖：

- 获奖详情：按团队展示，成员弹窗显示专业、备注和填报归属，并按权限显示编辑入口；保留查询与分页。
- Excel 导出：按实际获奖学生逐行导出新字段，保留学号文本。
- 学生“我的获奖”：按实际成员关系查询，未报名学生和普通团队成员均可看到自己的奖项。
- 学生补录：建立对应获奖成员记录，保留原补录审核流程，并阻止同名已有项目重复申报。
- 审核展示：使用奖项直接关联的赛事和实际成员，支持没有报名的奖项。
- 统计：通过奖项的赛事关联统计，未报名获奖不再被报名表连接漏掉；区分团队奖项数与学生获奖人次，移除不适用于免报名获奖的单项“获奖转化率”。
