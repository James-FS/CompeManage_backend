# 获奖填报限制

本清单适用于后台的手动录入、单赛事 Excel 导入和统一 Excel 导入。三个入口在后端共用获奖行校验。

## 人员与赛事权限

| 项目 | 当前规则 |
| --- | --- |
| 管理学院 | 院管理员账号须绑定管理学院。 |
| 学生 | 院管理员可以为同一团队填报不同学院的学生。系统按学号查询账号，以账号中的学院为准。 |
| 指导教师 | 可留空。填写时可选全校教职工，同一团队可登记不同学院的教师。系统按工号核对教职工身份，并读取姓名和学院。可填多位，工号不能重复，可用逗号、空格、顿号或分号分隔。 |
| 赛事 | 院管理员可填报本院赛事、赛事级别为「校级」的赛事，以及未绑定学院的赛事。跨院组队适用同一赛事范围。 |
| 报名 | 默认允许免报名填报。只有校级管理员可调整报名要求。开启后，每名学生须以队长或队员身份参加目标赛事，并有审核通过的报名。 |

跨院规则适用于新增填报。填报后的查询、编辑和导出仍按各自的学院权限执行。

## 填写与校验

| 项目 | 当前规则 |
| --- | --- |
| 必填项 | 每行填写一名学生。学号、姓名、所属学院、参赛项目名称、获奖时间、获奖类别和获奖等级必填。统一导入还须填写赛事名称。 |
| 学生资料 | 学号须对应系统中的学生或研究生账号，姓名和学院须与系统资料一致。专业可留空，填写时须与系统资料一致。 |
| 获奖时间 | 接受 Excel 日期单元格，也可填写 `YYYY-MM`、`YYYY.MM` 和 `YYYY-MM-DD`，统一按月保存。 |
| 获奖类别 | 接受校级、校赛、省级、省部级、国家级、国际级。校级和校赛统一保存为校赛，国际级统一保存为国家级。 |
| 获奖等级 | 保存为一等奖、二等奖或三等奖。冠军、金奖、特等奖归为一等奖，亚军、银奖归为二等奖，季军、铜奖归为三等奖。 |
| 字段长度 | 项目名称最多 255 字符，获奖等级原值最多 100 字符，学号最多 50 字节，备注最多 2,000 字符。 |
| 团队归组 | 同一赛事中项目名称相同的学生归为同一团队。团队各行的获奖类别、等级、年月和指导教师须一致。不同赛事的同名项目分别处理。 |
| 重复提交 | 同一赛事中，每名学生只能有一条获奖记录。同一团队的同一学生重复提交会跳过，保留已有记录和填报归属。同批将同一学生填入同一赛事的多个团队时，涉及的有效行都会报错。 |
| 已有奖项 | 导入数据与已有团队的奖项信息冲突时会报错。同名团队已有待审核或驳回的奖项时，导入无法覆盖。 |

模板还说明学生须为本校全日制本科生（不含继续教育、二级学院）。导入代码核验学生账号身份，未单独核验这一学籍条件。多个指导教师工号应在文本单元格中用顿号等分隔符填写，已被 Excel 合并为数值的工号需要重新输入。

## 批量导入

- 每批提交 1 至 5,000 行。Excel 只读取第一个工作表，统一导入的请求体上限为 20 MB。
- 统一导入按系统当前年份和完整赛事名称匹配有权填报的赛事。当前年份有多个同名赛事时，须在预览中选定目标赛事。赛事年份与获奖年月分别处理。
- 预览和提交都会校验。提交按行返回结果，通过的行可以写入，失败的行可以修正后再次提交。数据库写入异常会回滚该批次的写入。
